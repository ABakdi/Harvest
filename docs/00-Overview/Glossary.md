# Glossary

The farming metaphor runs through the whole app. These are the canonical terms — I use them consistently in the UI, the code, and these docs.

| Term | Meaning |
| :--- | :--- |
| **Seeds** | Goals and tasks I plant: [[Core-Entities#Project\|Projects]], Habits, To-Dos. |
| **Water** | Daily effort — every log/check-in waters the crops. |
| **Weeds** | Distractions and bad habits: doomscrolling, overspending. |
| **Soil Health** | Physical recovery — sleep quality and consistency. |
| **The Harvest** | What I reap daily: XP, streaks, real progress. |
| **Daily Harvest Goal** | Minimum productive actions per day to keep the Global Streak. |
| **Global Streak** | Consecutive days I met my Daily Harvest Goal. |
| **Streak Freeze** | A purchasable shield that protects the Global Streak for one missed day. |
| **Harvest Coins** | In-app currency earned by logging; spent on freezes and cosmetics. |
| **Farmer Rank** | Level title: Sprout → Seedling → Gardener → Harvester → Master Farmer. |
| **Check-in** | The act of logging progress on any entity. |
| **Daily Plan Ritual** | The evening/morning prompt to set tomorrow's (today's) tasks. |
| **Weed Pull** | A screen-time intervention (warning or block). |
| **Floating Daily Limit** | Remaining monthly budget ÷ remaining days. |
| **Sleep Debt** | Accumulated shortfall of actual vs. target sleep, paid down minute-for-minute. |
| **Harvest Day** | The app's logical day: 3:00 AM → 3:00 AM local time. See [[Business-Rules]]. |
